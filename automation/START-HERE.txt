WAHVENTORY COMPLETION UPDATE — 20.0.0.6

PLUGIN
Use Wahventory fork20.0.0.6 or newer. The compiled plugin package is
wahventory-v20.0.0.6.zip. The existing Dalamud repository remains:
https://raw.githubusercontent.com/MagicalMontra/wahventory/main/repo.json
This build must be published there before the installer can offer its update.
Keep the existing plugin configuration and auto-discard/blacklist lists.
No installed plugin or SND files were changed while preparing this update.

SND INSTALLATION
1. Replace Macro Sync with the complete Macro Sync.lua from this package.
2. Create a helper Lua macro named exactly Wahventory Sync and paste the
   complete Wahventory Sync.lua. Do not run either helper separately.
3. Replace Clear Inventory(wah) with the matching worker file.
4. In a caller, use:
     local Sync = require("Macro Sync.macro")
     if not Sync.Call("Clear Inventory(wah)", 450) then return end
   Put the next task after that guard. Caller example.lua shows this placement.

WHAT COMPLETION MEANS
Refresh DONE means inventory scanning, safety assessment and categorization
finished. External market-price fetching can continue independently.
Discard DONE means every queued stack passed the confirmation/slot-removal
check. Progress counts confirmed removals. Timeouts or unavailable inventory
fail instead of being counted as completed. No eligible items completes at
once; an empty configured auto-discard list is a configuration error.

The worker no longer contains fixed1/10/30-second waits. Its maximum refresh
wait is120 seconds, discard300 seconds; the caller's450-second maximum leaves
room for both. Success resumes immediately. Increase these limits for very
large queues if needed. A timeout does not cancel the discard queue.

The helper reads fresh per-game-process result files. Session IDs and operation
numbers prevent stale completion, missed brief RUNNING states and restart
confusion. FAILED/CANCELLED results stop dependent work. Keep one cleanup/
launcher active at a time; this is not a queue or lock for concurrent macros.

/wahventory status displays the latest refresh/discard result for checking.
New chat reports include Refresh DONE, Discard DONE, FAILED and CANCELLED.
Existing protections and configured disposal choices remain in effect.
